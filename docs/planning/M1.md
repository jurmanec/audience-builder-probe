# M1 roadmap

M1 is the template path over the gold set. A model, a brief, and the graph stay in later milestones. The path is done when the three known intents return an audience and every other gold objective returns none.

## 1. Shared schemas

One module defines the audience record, the brief record, and the tool inputs and outputs. The audience fields are `predicates`, `estimated_size`, and `status`. The brief fields are the approved audience, campaign id, offer, channels, and constraint. An incomplete brief fails validation. M1 writes an audience only. No brief file is written.

## 2. Typed tools

`count_predicate` stays the catalog check. A count tool accepts a predicate and returns a count or a rejection with an error class. Templates call this tool. They do not call `count_predicate` directly.

Add `list_usable_attributes` so the tool set can read the catalog. Leave campaign retrieval out. That is brief grounding, and briefs are M2.

A forbidden field or an impossible comparison is a rejection before any row is read. `g07` and `g08` never become a count.

## 3. Log every tool call

One record per call: tool name, validated arguments, outcome (row count, pass, rejection, or error class), duration, and a run id. That record is enough to see why a gold objective failed. A predicate that names `age_years` must show a rejection in the log and write no file. OpenTelemetry waits.

## 4. Run the three intents

Put the at-risk, heavy-use, and lapsed-video predicates in the template code, keyed by those intent names. Each one calls the count tool and returns an audience record with `status` set to `draft`. The sizes are 2,147, 440, and 1,052.

The template path receives only an intent name. A null intent stops. It does not open `eval/gold.json`.

## 5. Write a file only after success

A small runner takes an intent name. A matched intent may write the audience record. A miss, a rejection, or a schema failure writes nothing.

The eval harness may read `eval/gold.json` to choose the intent and to check the size band. `g01` through `g03` pass `at-risk renewal`, `heavy-use upgrade`, and `lapsed video offer`. `g04` through `g08` produce no audience file.

A short how-to says how to run that command and where the log is written. The public README stays with M3, when all three paths exist.

## Done when

Those behaviors hold for all eight gold objectives. The predicates stay in the template code. `eval/gold.json` keeps the bands and the `no_audience` outcomes, and it does not gain the answers. No model calls, revision, graph, one-shot path, or UI.
